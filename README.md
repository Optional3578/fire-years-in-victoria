# Fire years in Victoria

An interactive calendar and map of satellite fire detections in Victoria, Australia. Choose a region or draw an area to explore daily activity and unusual periods.

The GitHub Pages version runs entirely in the browser using a compact snapshot derived from the project's harmonized dataset. The original source archives and local Python database are not required to view the demo.

Data source: NASA FIRMS active fire detections (MODIS Collection 6.1 and VIIRS S-NPP). The underlying data and calibration are described in the project methodology on the page.
